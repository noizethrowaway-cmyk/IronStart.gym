Progression rules

All target reps completed

Increase next time by the exercise's increment.

Missed any target reps

Repeat the same load next time. Don't force bad reps.

Missed the same lift 3 times

Consider a 10% reduction and review sleep, food, recovery and technique before building again.

Settings

About this programme

This hybrid uses Starting Strength-style squat 3×5 and deadlift 1×5, with StrongLifts-style 5×5 bench, overhead press and barbell row. Workout A and B alternate. It is a practical template, not an exact reproduction of either official programme.
